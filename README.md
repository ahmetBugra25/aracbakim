🚗 Araç Bakım: Modern Android Uygulaması Yayında! 🎉

Merhaba Github topluluğu! 👋

Uzun süredir üzerinde çalıştığım "Araç Bakım" uygulamasını Google Play Store'da yayınlamanın heyecanını yaşıyorum! 🚀

📊 Proje Hakkında:
Araç Bakım, araç sahiplerinin tüm bakım, yakıt, gider ve hatırlatıcı kayıtlarını tek bir platformda yönetmesini sağlayan kapsamlı bir mobil uygulama. Kullanıcılar aracın tüm geçmişini detaylı istatistikler ve grafiklerle takip edebiliyor.

🔧 Kullanılan Teknolojiler:
- Kotlin - %100 Kotlin ile geliştirildi
- GeminiAPI - Gemini Yapay zeka entegrasyonu
- Jetpack Compose - Modern, deklaratif UI
- Room Database - Yerel veri yönetimi ve migration
- Hilt (Dagger) - Dependency Injection
- Coroutines & Flow - Reaktif programlama
- MVVM Architecture - Clean architecture prensiplerine uygun
- Material Design 3 - Modern UI/UX
- Navigation Component - Type-safe navigasyon
- WorkManager - Arka plan işlemleri
- Firebase Analytics & Crashlytics - Uygulama izleme
- AdMob - Monetization

✨ Öne Çıkan Özellikler:
✅ Yapay zeka ile aracınız hakkında bilgi alışverişi yapabilme
✅ LPG + Benzin çift yakıtlı araç desteği
✅ Otomatik ortalama tüketim hesaplama
✅ Km başı maliyet analizi
✅ Detaylı istatistikler ve karşılaştırma grafikleri
✅ Akıllı hatırlatıcı sistemi
✅ JSON tabanlı yedekleme/geri yükleme
✅ Dark mode desteği
✅ Home screen widget


📈 Gelecek Planlar:
